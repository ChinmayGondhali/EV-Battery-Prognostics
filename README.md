# EV Battery Prognostics

An end-to-end machine learning project for lithium-ion battery State of Health (SOH) estimation and battery prognostics using the Oxford Battery Degradation Dataset 1.

## Current Progress

- Oxford Battery Degradation Dataset 1 loaded
- Battery capacity extraction
- SOH calculation
- Feature engineering
- Exploratory Data Analysis
- Data quality analysis
- Random Forest SOH estimation
- Gradient Boosting SOH estimation
- Cell-wise GroupKFold validation
- Feature importance analysis

## Dataset

This project uses the Oxford Battery Degradation Dataset 1.

The raw dataset is not included in this repository because of its large file size.
